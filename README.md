# DropPilot eBay OAuth pages

This static site provides the DropPilot privacy policy and eBay OAuth return pages.

After enabling GitHub Pages, use these URLs in the Sandbox RuName form:

- Privacy policy: `https://satoshipassmore-prog.github.io/droppilot-ebay-oauth/privacy.html`
- Accepted URL: `https://satoshipassmore-prog.github.io/droppilot-ebay-oauth/callback.html`
- Declined URL: `https://satoshipassmore-prog.github.io/droppilot-ebay-oauth/declined.html`

Do not place eBay credentials or refresh tokens in this repository.
